# VoidMob

**Privacy-focused mobile services platform.** Real mobile proxies, non-VoIP SMS verification, and global eSIM data from one dashboard, one prepaid balance, no KYC.

## What we offer

🌐 **Mobile Proxies** - Real 4G/5G carrier IPs, not datacenter or residential. Shared pay-per-GB plans with rotating or sticky sessions, or a dedicated device that is yours alone. Country and city targeting, HTTP(S) and SOCKS5, works with every major antidetect browser.

📱 **SMS Verification** - Non-VoIP numbers on real carrier infrastructure that pass the checks VoIP numbers fail. Three ways to use them: a one-time code, a rental for 3 to 30 days, or a private dedicated number on a monthly plan that works across most platforms.

✈️ **Global eSIM** - Instant data plans in 180+ destinations. We show the exit country of every plan before you buy, so your IP matches where you are. QR code delivered in seconds.

🤖 **MCP Server for AI agents** - Open-source [Model Context Protocol](https://voidmob.com/mcp) server with 28 tools that let Claude, Cursor, or any MCP client provision proxies, numbers, and eSIMs on their own. MIT licensed, with a free sandbox mode.

## Why VoidMob

- **Real infrastructure** - Carrier networks and genuine SIM cards, not emulation or VoIP.
- **Privacy by design** - No ID, no KYC, no profiling. Pay with crypto, activate instantly.
- **Transparency** - We publish the routing details other providers hide.
- **One account** - Proxies, SMS, and eSIM share a single wallet and a single API key.
- **Built to automate** - REST API, self-serve API keys, and an MCP server so agents can do the work.

## Get started with the MCP server

```bash
npx -y @voidmob/mcp
```

Set `VOIDMOB_SANDBOX=1` to try every tool against mock data with a play-money balance, no API key needed. For production, generate a key at [dashboard.voidmob.com/developers/api-keys](https://dashboard.voidmob.com/developers/api-keys).
